# 两个平台独立部署

此说明替代早期 Pages 调用 Cloudflare API 的设计。用户要求保留两个部署平台，但任何一个站点都不依赖另一个站点。

- Pages 模式：静态资源使用 Vite base 路径；数据请求由 src/urls.js 映射到 Streets GL 和 Nominatim 的公共 HTTPS 接口。两者支持浏览器 CORS。Pages 不运行代理服务。
- 本地、Node 和 Cloudflare 模式：保持 /api/tiles 和 /api/geocode 同源代理，静态资源使用根路径。
- VITE_API_BASE_URL 不再参与构建；构建模式固定数据路由，避免仓库遗留变量导致平台混用。
- Cloudflare 默认清空跨域代理白名单。同源接口与可选显式 CORS 配置处理保留。
- GitHub Actions 只构建并发布 Pages，不需要 Cloudflare 账号或部署步骤。
